## Lỗi hay mất điểm ở Task 1

- Objective chỉ lặp lại deliverable ("xây dựng hệ thống"). Objective phải là **kết quả** đo được.
- Stakeholder analysis không dẫn tới thay đổi nào — đề yêu cầu nói rõ phân tích đã sửa gì trong objectives, scope hoặc cách làm.
- Assumption không ghi nguồn, nên không biết cái nào client xác nhận, cái nào nhóm tự đặt.
