# Bằng chứng tương tác client

Ảnh chụp email, tin nhắn LMS, biên bản có xác nhận.

Đặt tên: `<mã>-<ngày>-<mô-tả>.png`

Dòng nào trong Client Log có câu trả lời quan trọng thì cột Bằng chứng phải trỏ tới một file ở đây.
Không có bằng chứng thì coi như câu trả lời chưa được xác nhận — ghi rõ "chờ xác nhận" trong log.
