# Weekly project log

Đề yêu cầu (Task 3.2): planned work, actual work, planned effort, actual effort, issues, management actions.

- **TV1 tự viết**, mỗi Chủ nhật trước 22:00, và tự commit. Đây là bằng chứng quản lý mang tên PM.
- Tên file: `week-NN.md` theo số tuần của lịch môn học (`week-05.md` = tuần bắt đầu 21/09).
- Tuần không họp thì ghi rõ "không họp".
- Mỗi log có ít nhất **một hành động quản lý cụ thể**.
