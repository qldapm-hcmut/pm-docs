## 3. Product Flow Diagram (PFD)

```mermaid
flowchart TD
    REQ[Validated Scope & Requirements]

    DB[Database Design]
    API[API Contract]
    TEST[Test Specification]

    AUTH[Authentication & Authorization]
    EVENT[Event Management]
    REG[Registration & Waitlist]
    CHECK[Check-in & Attendance]
    REPORT[Reporting & Export]
    UI[User Interface]

    SYS[Tested Integrated System]
    DEPLOY[Deployed System]
    HAND[Handover Documentation]

    REQ --> DB
    REQ --> API
    REQ --> TEST

    DB --> AUTH
    API --> AUTH

    DB --> EVENT
    API --> EVENT

    EVENT --> REG
    REG --> CHECK

    REG --> REPORT
    CHECK --> REPORT

    REQ --> UI

    AUTH --> SYS
    EVENT --> SYS
    REG --> SYS
    CHECK --> SYS
    REPORT --> SYS
    UI --> SYS
    TEST --> SYS

    SYS --> DEPLOY
    DEPLOY --> HAND
```

## 4. A15 acceptance check

- [x] PFD mô tả product dependency, không phải task schedule.
- [x] Core scope được bao phủ và không đưa feature ngoài scope vào.
