## Hướng dẫn chạy và tài khoản demo

1. Checkout đúng hai SHA và làm theo README của hai repo. README BE có phần chạy toàn bộ bằng Docker, seed demo và kiểm tra readiness. README FE ghi cấu hình kết nối API và đăng nhập. [README BE](https://github.com/qldapm-hcmut/ticket-system-uni-be/blob/24e08ce36dabd3a07ae6f38e31d3d28bb4ab22e0/README.md), [README FE](https://github.com/qldapm-hcmut/ticket-system-uni-fe/blob/58a81b8f2b314687fe0c9f68a55f5d3ac069c31f/README.md)
2. Chọn `AUTH_MODE=local` cho demo. Tạo token tại máy bằng `dev-token` theo README BE cho từng vai `student`, `organizer` hoặc `admin`. Organizer mẫu thuộc đơn vị DEMO. Trên FE chọn **Dán access token để test → Dán token trực tiếp**. Dán access token vào ô tương ứng, có thể để trống refresh token. [Hướng dẫn và kiểm tra stack P1](../quality/results/main-2026-11-27-e2e/p1/report.md#stack-bàn-giao)
